# MACE для предсказания энергии по координатам (данные Orca)

## Что в датасете

`dataset.extxyz` — 3229 структур в extxyz-формате:
`Properties=species:S:1:pos:R:3:forces:R:3 energy=<число> pbc="F F F"`

- 9–20 атомов на структуру, 19 химических элементов (Fe, Cu, Co, Cr, Mn, Ni, Zn,
  As, B, Br, C, Cl, F, H, I, N, O, P, S) — то есть это набор разных
  металл-органических комплексов, а не траектория одной молекулы.
- Для каждой структуры есть `energy` (эВ) и `forces` (эВ/Å) — они уже читаются
  ASE как `atoms.get_potential_energy()` / `atoms.get_forces()`, отдельно парсить
  строку не нужно.
- PBC отсутствует (`pbc="F F F"`) — это изолированные молекулы, не кристаллы.

## Почему mace-torch, а не MACE «с нуля»

MACE (Batatia et al., NeurIPS 2022) — это конкретная эквивариантная
message-passing архитектура (E(3)-инвариантные/эквивариантные признаки на
основе сферических гармоник + ACE-контракция высокого порядка). Официальная
реализация `mace-torch` — это и есть эта архитектура: она поддерживается
авторами, оптимизирована (в том числе под ту задачу, которая у вас в проекте —
ускорение вычислений вместо DFT), и совместима с форматом extxyz из Orca
"из коробки". Переписывать её вручную имеет смысл только в учебных целях —
для продакшен-заменителя DFT лучше использовать проверенную реализацию.

## Файлы

- `prepare_data.py` — делит `dataset.extxyz` на train/valid/test (уже
  протестирован на вашем файле: 2585/322/322 структур).
- `config.yaml` — конфиг обучения, подобран под размер датасета:
  - `r_max: 5.0` Å — радиус обрезки соседей;
  - `num_interactions: 2`, `correlation: 3` — 2 слоя message passing с
    контракцией 3-го порядка (тело-порядок фич до 4) — баланс точности и
    скорости для датасета среднего размера;
  - `E0s: average` — референсные атомные энергии оцениваются линейной
    регрессией по датасету (изолированных атомов в данных нет);
  - `forces_weight: 10` — силы участвуют в обучении, это сильно улучшает
    качество предсказания энергии (более гладкая поверхность), даже если
    в проде нужна только энергия. Если силы не нужны вовсе — поставьте
    `forces_weight: 0`.
- `train.sh` — установка `mace-torch`, подготовка данных, запуск обучения,
  оценка на тесте.
- `predict.py` — инференс обученной модели, считает MAE/RMSE по энергии.

## Запуск

```bash
pip install mace-torch
bash train.sh
```

Требования: GPU с ~4+ ГБ VRAM (на CPU будет работать, но медленно),
свободное место на диске ~3–5 ГБ под torch/cuda-зависимости.

## Дальнейшие шаги / что покрутить

- `num_channels: 128 -> 64` — если не хватает памяти или нужно быстрее.
- `max_L: 1 -> 2` — точнее, но заметно медленнее (эквивариантные фичи высшего
  порядка).
- Для чисто energy-задачи без forces можно поставить `forces_weight: 0` —
  обучение будет быстрее, но точность по энергии обычно немного хуже, чем
  при совместном обучении на energy+forces.
- После обучения `models/mace_energy_model.model` можно использовать и как
  ASE-калькулятор (`MACECalculator`) для быстрой оптимизации геометрии /
  сканов PES вместо повторных запусков Orca — собственно то, о чём ваш
  проект.
